## Что показать

1. Открой `index.html` в Chrome. Интернет нужен для Bootstrap с CDN.
2. Открой DevTools (F12), включи режим устройств (Ctrl+Shift+M).
3. По очереди введи ширину 375, 768 и 1280. Покажи 1, 2 и 3 карточки в строке в обеих секциях.
4. При 375 открой и закрой меню. Нажми The legends: это якорная ссылка на `id="legends"`.
5. Покажи, что текст hero идёт первым на телефоне, а фото — слева на компьютере. Маленькая подпись под кнопкой скрыта на телефоне.

## Как устроен код

- `index.html` — содержание и структура: nav, main с четырьмя section и footer.
- `style.css` — цвета, шрифты, фотографии и ручная адаптивность секции stars.
- `assets/images` — фотографии; при открытии страницы они берутся из проекта.
- Bootstrap CSS отвечает за готовую сетку и компоненты. JS bundle нужен для раскрытия меню. Собственного JavaScript нет.
- `<meta name="viewport" content="width=device-width, initial-scale=1">` позволяет использовать реальную ширину мобильного экрана.
- Свой CSS подключён после Bootstrap, поэтому при одинаковой специфичности более поздние правила могут переопределять предыдущие.

## Task 1

`.stars-grid` изначально имеет `display: grid` и `grid-template-columns: 1fr`. Это mobile-first: сначала описан телефон.

`@media (min-width: 768px)` включает две равные колонки: `repeat(2, 1fr)`. `@media (min-width: 992px)` включает три: `repeat(3, 1fr)`. При 1280 работают оба условия; более позднее правило для одного и того же свойства задаёт три колонки.

`fr` — доля свободного места. `gap` — расстояние между ячейками. Ширина обёртки задана в процентах, а не фиксированным числом пикселей.

При 768 также увеличиваются заголовок и вертикальные отступы. При 992 заголовок и описание выстраиваются рядом. Внутри секции нет Bootstrap-классов, но глобальный Bootstrap Reboot всё ещё задаёт некоторые стандартные стили HTML-элементов.

## Task 2

- `container` ограничивает и центрирует содержимое, `row` создаёт строку, `col-*` — колонки.
- Сетка Bootstrap разделена на 12 долей. `col-12` занимает всю строку, `col-md-6` половину от 768px, `col-lg-4` треть от 992px.
- `order-1 order-lg-2` у текста: первым на маленьком экране, вторым на большом. У изображения — наоборот.
- `d-none d-md-block` скрывает подпись до 768px и показывает начиная с 768px.
- `navbar-expand-md` разворачивает меню начиная с 768px. На телефоне кнопка с `data-bs-target="#mainNav"` управляет блоком с `id="mainNav"`.
- `card`, `card-body`, `card-title` — готовый компонент карточки. Его внешний вид дополнен своим CSS.
- `py-5` — вертикальные отступы, `p-4` — отступы со всех сторон, `mb-0` — убрать нижний отступ, `d-flex` — Flexbox.
- `object-fit: cover` заполняет рамку фотографией с обрезкой краёв без искажения пропорций.

## Что могут попросить изменить

1. **Сделать две колонки на ноутбуке в stars:** поменять `repeat(3, 1fr)` на `repeat(2, 1fr)` в правиле от 992px.
2. **Сделать две колонки легенд на ноутбуке:** у всех трёх обёрток поменять `col-lg-4` на `col-lg-6`.
3. **Перенести ручной брейкпоинт:** изменить число в `min-width`. Это не меняет брейкпоинты Bootstrap.
4. **Добавить футболиста:** скопировать `article.star-card`, заменить имя, текст, src и alt. Сетка автоматически добавит новую строку.
5. **Показать подпись на телефоне:** удалить `d-none d-md-block`.
6. **Изменить цвет:** поменять переменную `--forest` в `:root`.

## Короткое сравнение

Ручной CSS даёт прямой контроль над сеткой и брейкпоинтами, но требует писать и поддерживать правила. Bootstrap позволяет быстрее собрать типовой макет готовыми классами, но требует помнить их назначение. Здесь одинаковый результат 1/2/3 получен двумя способами.
